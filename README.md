# EZFolder

Windows 10 x64 资源管理器标签栏。在同一个窗口里切换文件夹，也可以把后来打开的资源管理器窗口收进已有窗口的标签页。

标签栏跟随 Windows 的应用主题。深色模式采用黑底、浅色文字和细边框选中标签，使用系统界面字体和 Windows 主题复选框。浅色与高对比度模式沿用原生控件绘制。

## 开关与合并

Windows 10 资源管理器右上角、功能区折叠箭头左侧有一个标签图标。单击可显示或隐藏当前窗口的标签栏，悬停可查看操作提示。图标下方的蓝线表示标签栏已显示。

安装程序会为当前用户创建登录启动快捷方式，运行独立的原生入口程序。它负责显示这个按钮，卸载时一起移除。

- 在 Windows 开始菜单搜索 **开启 EZFolder** 或 **关闭 EZFolder**，可以对当前用户的资源管理器窗口显示或隐藏标签栏。关闭后新打开的文件夹使用独立窗口。日常切换无需管理员权限。
- 标签栏右侧的 **合并新窗口** 默认勾选。已有可接收标签的窗口时，EZFolder 会尽早请 Windows 桌面窗口管理器暂缓显示新窗口。目标标签确认打开该目录后，再关闭临时窗口。扩展加载前已显示的画面仍可能短暂可见。
- 没有接收窗口时，第一个文件夹照常显示。如果交接耗时较长，独立计时器会在约一秒后恢复新窗口显示。
- 新窗口开始显示时立即检查目录。启动阶段尚未就绪时每 25 毫秒重试，等待较久后降频；空闲窗口保持低频检查。
- 取消勾选可保留标签栏，同时独立打开后续窗口。该选择按用户保存。重新勾选从下次开窗生效，已打开的窗口保留。
- 使用“在文件夹中显示”定位已选中文件时，会保留带选区的窗口。

## 编译与启用

在项目目录用 PowerShell 编译：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

需要 64 位 MinGW-w64 的 `g++`，编译输出为 `build\EZFolder.dll`。在项目目录使用管理员 PowerShell 安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装程序将 DLL 复制到 `Program Files\EZFolder`，注册工具栏并创建开始菜单快捷方式。安装后运行 **开启 EZFolder**。升级时，如果仍看到旧标签栏，先保存工作并注销、重新登录，再运行 **开启 EZFolder**。

## 操作

- **新建**复制当前文件夹标签。在新标签里照常双击文件夹或输入地址，切回旧标签即可回到原目录。
- 单击标签切换当前窗口的位置。**关闭**移除当前标签，鼠标中键可关闭指定标签。最后一页会保留。
- 标签栏获得焦点时，`Ctrl+T` 新建、`Ctrl+W` 关闭、`Ctrl+Tab` 和 `Ctrl+Shift+Tab` 切换。
- 标签保存 Windows Shell 文件夹位置，包括磁盘目录和「此电脑」等虚拟文件夹。前进、后退沿用窗口自身的历史。关闭窗口后结束本次标签会话。

## 卸载

取消勾选 EZFolder，关闭使用它的资源管理器窗口，在管理员 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall
```
