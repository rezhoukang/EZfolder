# EZFolder

Windows 10 x64 资源管理器标签栏。在同一个窗口里切换文件夹，也可以把后来打开的资源管理器窗口收进已有窗口的标签页。

标签栏跟随 Windows 的应用主题和系统字体。深色模式下，当前标签以深灰色圆角背景标出。每页显示目录名，**＋** 固定在栏的最右端。标签会随数量增多而压窄。名称显示不全时，把鼠标停在该页上即可在下方看到全名。

## 开关与合并

Windows 10 资源管理器右上角、功能区折叠箭头左侧有一个标签图标。单击可显示或隐藏当前窗口的标签栏，悬停时显示 `EZfolder`。右键单击图标，选择 **设置**，会打开独立的设置窗口。选择「此电脑」或「快速访问」后，点击 **确定** 保存新标签的默认位置。

安装程序会为当前用户创建登录启动快捷方式，运行独立的原生入口程序。它负责显示这个按钮，卸载时一起移除。

Windows 10 1903 及以上版本的设置页使用系统自带的 XAML 控件，随 Windows 应用主题和强调色更新。更早的 Windows 10 使用标准桌面设置对话框。

- 在 Windows 开始菜单搜索 **开启 EZFolder** 或 **关闭 EZFolder**，可以对当前用户的资源管理器窗口显示或隐藏标签栏。关闭后新打开的文件夹使用独立窗口。日常切换无需管理员权限。
- 标签栏开启后，普通新窗口会自动合并。连续打开多个文件夹时，接收窗口先把各个目录存为标签，再集中切换一次。每个临时窗口都会在确认目录已经交接后关闭。扩展加载前已显示的画面仍可能短暂可见。
- 容量按标签栏实际宽度计算：预留 32 个逻辑像素给加号、6 个给边距，其余宽度每 24 个逻辑像素可容纳一页。满员后该窗口暂停新增和接收合并，腾出空间后自动恢复。缩窄窗口会继续压缩已有标签，所有页保持在同一行。
- 没有接收窗口时，第一个文件夹照常显示。等待合并时，EZFolder 请 Windows 暂缓显示临时窗口。单个窗口就绪后等待约一秒仍未交接，会恢复显示；连续开窗时会给同一批交接更多时间，每个窗口从开始遮蔽起最多等待约八秒。
- 新窗口开始显示时立即检查目录。启动阶段尚未就绪时每 25 毫秒重试，等待较久后降频；空闲窗口保持低频检查。
- 使用“在文件夹中显示”定位已选中文件时，会保留带选区的窗口。

## 编译与启用

在项目目录用 PowerShell 编译：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

在 Windows 10 1903 或更高版本的 64 位 Windows 上编译。构建脚本使用 MinGW-w64 的 `g++` 编译资源管理器扩展和入口程序，并使用系统自带的 .NET Framework 编译器及 Windows 运行时元数据编译独立设置程序。输出位于 `build`。在项目目录使用管理员 PowerShell 安装：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

安装程序将 DLL 复制到 `Program Files\EZFolder`，注册工具栏并创建开始菜单快捷方式。安装后运行 **开启 EZFolder**。升级时，如果仍看到旧标签栏，先保存工作并注销、重新登录，再运行 **开启 EZFolder**。

## 操作

- **＋** 默认打开「此电脑」。在入口的右键设置中改为「快速访问」后，下一次新建就会生效。
- 单击标签切换目录，单击页上的 **×** 或用鼠标中键关闭该页。窄标签的 **×** 在悬停时显示。关闭最后一页会回到设置中的新标签位置。
- 按住标签名称，拖出标签栏再松开，即可把该页移到独立窗口。新窗口打开该目录后，原窗口才移除该页。只有一页时，拖出会移动现有窗口。
- 标签栏获得焦点时，默认用 `Ctrl+T` 新建、`Ctrl+W` 关闭、`Ctrl+Tab` 切到下一页、`Ctrl+Shift+Tab` 切到上一页。右键入口进入 **设置 → 快捷键**，点击某个动作的按键组合后直接按下新组合，按 `Esc` 可取消录入。**重置默认值** 会把四个快捷键和新标签打开位置一起恢复为默认值。点击 **确定** 保存，点击 **取消** 放弃本次更改。
- 标签保存 Windows Shell 文件夹位置，包括磁盘目录和「此电脑」等虚拟文件夹。前进、后退沿用窗口自身的历史。关闭窗口后结束本次标签会话。

## 卸载

取消勾选 EZFolder，关闭使用它的资源管理器窗口，在管理员 PowerShell 中执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Uninstall
```
